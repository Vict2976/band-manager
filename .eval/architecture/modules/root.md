# Module: (root)

Provides root-level build and runtime configuration for Next.js image loading and PostCSS Tailwind integration.

## Key files
- `next.config.ts`: Defines Next.js settings, configuring image domains for Firebase Storage, allowing SVGs, and enabling optimization.
- `postcss.config.mjs`: Defines PostCSS configuration utilizing @tailwindcss/postcss plugin.

## Public interface
- default nextConfig
- default config

## Dependencies
- next
- @tailwindcss/postcss
